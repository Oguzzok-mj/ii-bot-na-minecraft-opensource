# ИИ бот на Майнкрафт — Open Source

Нейро-фармер для **Minecraft Java 1.20.1**: добыча по заданию, возврат на базу, сбор выпавших предметов и автоматическая подготовка снаряжения. Python управляет задачами и моделями, Mineflayer — действиями в мире. Интерфейс — отдельное минималистичное окно в стиле Linux-терминала с видом от лица бота.

**Поддержка: Discord `tripeg.hvh`** — добавь в друзья и напиши о проблеме. Ошибки и предложения также можно отправлять через Issues этого репозитория.

## Возможности

- Выбор ресурса и количества в стаках; после выполнения бот возвращается домой и складывает добычу в сундуки.
- Инвентарь, координаты дома и порталов, пауза и продолжение задания.
- Поиск жил в загруженных чанках, ESP руд и лавы, обход препятствий и проверка подбора добычи.
- Подготовка кирок, переплавка, улучшение брони, зачарование и незеритовые улучшения при наличии нужных ресурсов и блоков на базе.
- Создание обсидиана из источника лавы и воды, когда безопасного пути к природному обсидиану нет.
- Локальный Qwen как дополнительный планировщик; без него работает небольшая модель выбора жил.

Это экспериментальный проект. Действия зависят от геометрии мира, доступных ресурсов и ответа сервера. Полное прохождение, достижение всех зачарований и безопасная работа в любом мире не гарантированы. Частота отображения ограничивается производительностью компьютера; целевая частота интерфейса — 120 FPS, сервер Minecraft обновляет игру отдельно.

## Запуск из исходников

Основная платформа — **Windows x64**, **Python 3.11**, **Node.js 22 или новее**. Minecraft запускается отдельно. Java-версия игры: **1.20.1**.

Скачай репозиторий через **Code → Download ZIP**, распакуй и открой PowerShell в его папке:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
npm ci
.\.venv\Scripts\python.exe launcher.py
```

Открой мир Minecraft для сети или запусти сервер. В терминале приложения задай свои значения:

```text
host 127.0.0.1
port 25565
username NeuroFarmer
home 0 64 0
connect
```

`25565` и `0 64 0` — примеры. Для LAN используй порт, который показала игра; координаты дома укажи рядом со своими сундуками. Через меню «руды» выбери ресурс и стаки, затем нажми запуск. `help` показывает остальные команды. `auto on` включает подготовку и улучшение предметов во время добычи; `qwen off` выбирает быстрый локальный планировщик жил.

Графическое приложение использует offline-авторизацию сервера. Для сервера с Microsoft-авторизацией используй командный режим:

```powershell
.\.venv\Scripts\python.exe main.py connect --host localhost --port 25565 --version 1.20.1 --username YOUR_ACCOUNT --auth microsoft --viewer
```

Сессии авторизации и настройки сохраняются только локально в `data/`. Для автоматических улучшений нужны доступные сундуки, верстак, печи, стол зачарования, наковальня и кузнечный стол; для незерита в 1.20.1 нужны также шаблоны незеритового улучшения. Указывай координаты порталов через вкладку интерфейса или команду `portal X Y Z overworld` / `portal X Y Z the_nether`.

## Как устроен ИИ

Бот получает состояние мира через Mineflayer: блоки, сущности, инвентарь и состояние персонажа. Он не управляет игрой по изображению экрана.

- **`brain.py`** — небольшая NumPy-сеть для действий с деревом. Демонстрационные веса обучены на синтетических примерах правил. Команды `record` и `train` позволяют записывать успешные действия и обучать свою сеть.
- **`miner_learning.py` / `ore-policy.js`** — сеть `12 → 32 → 16 → 1`, оценивающая жилы по расстоянию, препятствиям, опасностям и времени добычи. В репозитории есть готовые компактные веса. Это обучение по оценкам алгоритмического учителя, а не reinforcement learning. `train miner` использует локально собранные примеры; исходные записи частного мира сюда не включены.
- **`qwen_planner.py`** — предварительно обученная **Qwen3-1.7B**, которая выбирает допустимую цель из подготовленного списка. Ответ проверяется перед исполнением. Qwen здесь не дообучен; правила и примеры передаются в запросе. Движение, крафт, сбор добычи и проверки выполняются игровыми модулями.

## Qwen — необязательно

Большая модель и исполняемые файлы llama.cpp не хранятся в Git. Для режима `qwen on`:

1. Скачай `Qwen3-1.7B-Q8_0.gguf` из [официального репозитория Qwen](https://huggingface.co/Qwen/Qwen3-1.7B-GGUF/tree/main) и положи в `models/` (около 1,83 ГБ).
2. Скачай `llama-b11429-bin-win-vulkan-x64.zip` из [релиза llama.cpp b11429](https://github.com/ggml-org/llama.cpp/releases/tag/b11429). Распакуй все файлы так, чтобы получился путь `runtime/qwen/llama-server.exe`; DLL должны лежать рядом с ним.
3. Проверь SHA-256 модели:

```powershell
Get-FileHash models/Qwen3-1.7B-Q8_0.gguf -Algorithm SHA256
```

Ожидаемый хеш: `061b54daade076b5d3362dac252678d17da8c68f07560be70818cace6590cb1a`.

Qwen запускается локально: сначала используется Vulkan, затем при необходимости CPU. На CPU решения могут быть значительно медленнее. Само приложение не отправляет запросы модели в облако.

## Проверки

После установки зависимостей:

```powershell
.\.venv\Scripts\python.exe tests/run_checks.py
```

Набор проверяет квоты и возврат домой, сбор дропа, маршруты, опасности, подготовку инструментов, решения Qwen и создание обсидиана на моделях игрового состояния. Эти проверки не заменяют испытания на реальном сервере. GitHub Actions запускает тот же набор на Windows.

## Сборка EXE

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\.venv\Scripts\python.exe scripts/build_windows.py
```

Результат: `dist/MinecraftNeural-v8/MinecraftNeural-v8.exe`. Распространяй всю папку, а не один EXE: рядом нужны `_internal`, JavaScript-модули, `node_modules` и компактные модели. Node.js должен быть установлен на компьютере пользователя. Для Qwen отдельно добавь `runtime/qwen` и файл GGUF по инструкции выше.
